# Kurier Kalkulator

Показывает поверх экрана заказа в курьерском приложении:
- **зл/км** = цена ÷ (км до ресторана + км доставки)
- **зл/час** = цена ÷ расчётное время, где время = км ÷ скорость + ожидание/передача

Карточка зелёная / оранжевая / красная по вашим порогам. Появляется, пока на экране
кнопка «Прийняти», и исчезает после принятия или отказа. Приложение только читает экран,
ничего не нажимает и не отправляет в интернет (разрешения INTERNET нет).

## Сборка
1. Установить Android Studio, открыть папку `CourierCalc`, дождаться Gradle Sync.
2. Подключить телефон (отладка по USB) и нажать Run, либо Build → Build APK(s).

## Включение на телефоне
1. Открыть приложение → «Открыть настройки спец. возможностей» → Kurier Kalkulator → включить.
2. Android 13+: если пункт серый, зайти в Настройки → Приложения → Kurier Kalkulator →
   меню ⋮ → «Разрешить ограниченные настройки», затем повторить п. 1.
3. В самом приложении задать среднюю скорость и время ожидания под ваш город.

## Если карточка не появляется
Курьерское приложение могло назвать кнопку по-другому. Добавьте слово в `acceptWords`
в `OfferParser.kt`. Юнит-тест на тексты с вашего скриншота: `OfferParserTest.kt`.
